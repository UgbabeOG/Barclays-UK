# **App Name**: Barclays UK

## Core Features:

- Simulated Login: A mock login page to access the application as a pre-configured user (Douglas Henshall).
- Account Dashboard: Display a dashboard with mock account balances for various accounts, including an available balance of approximately £6,000,000.
- Transaction History: Browse and filter mock transaction history for each simulated account.
- Mock Fund Transfer: An interface to initiate mock fund transfers between internal simulated accounts or to mock external payees.
- Support & Help: Access dummy support links and general help information for banking services.
- AI Banking Assistant: An AI-powered virtual assistant tool to respond to common banking queries based on simulated data, providing guidance on mock transactions or account details.

## Style Guidelines:

- Primary color: A vibrant, trustworthy Barclays blue (`#1755C7`) to evoke stability and corporate identity.
- Background color: An almost white, subtly blue-tinted background (`#F7F9FC`) for a clean, open, and professional feel.
- Accent color: A subtle, muted red (`#BF6D78`) used sparingly for alerts, call-to-action highlights, or attention-grabbing elements.
- Headline and body text font: 'Inter' (sans-serif) for its modern, clear, and highly legible appearance suitable for a banking interface.
- Utilize a consistent set of clean, outline-style icons for navigation, actions, and categorizations, ensuring quick recognition and clarity.
- Implement a structured, grid-based layout with generous white space to ensure information is presented clearly and remains uncluttered across various screen sizes.
- Incorporate subtle and swift animations for interactive elements such as button clicks, form submissions, and data loading states, providing smooth user feedback without being distracting.
